# Laterne „Pfeil“

3D-gedruckte Laterne für den Laternenumzug: ein Raumjäger mit Flammen, Scheinwerfern und Laserkanonen aus einer adressierbaren LED-Kette, gesteuert von einem ESP32-C3 im Griff am Stab.

- [ANLEITUNG.md](ANLEITUNG.md) – Druck, Zusammenbau, Verkabelung, Code
- [EINKAUFSLISTE.md](EINKAUFSLISTE.md) – Teile
- `druck-k2/` – STL-Dateien (alle ohne Stützen druckbar), `onshape-step/` – STEP
- `elektronik/` – Steckplan und Arduino-Sketch, `firmware/` – fertige Firmware für das Update über WLAN
- `quelle/` – CadQuery-Modell, `bilder/` – Renderings
